Prompt pronto para uso
Você é um especialista em classificação de periódicos científicos. Abaixo está uma lista de periódicos. Para cada um, classifique a ÁREA PRINCIPAL usando apenas uma das categorias abaixo: CATEGORIAS: - Odontologia - Medicina - Enfermagem - Farmácia - Saúde Pública - Multidisciplinar em Saúde - Biologia / Ciências Básicas - Engenharia / Tecnologia - Outra área (especifique) REGRAS: - Responda SOMENTE com uma tabela markdown, sem nenhum texto antes ou depois, sem título, sem introdução, sem conclusão, sem numeração de itens fora da tabela - A tabela deve ter as colunas: # | Periódico | Área Principal | Confiança | Áreas Secundárias - Confiança ALTA = nome do periódico deixa claro a área - Confiança MÉDIA = é possível inferir pela especialidade, mas não é óbvio - Confiança BAIXA = periódico genérico ou desconhecido, difícil de classificar - Se um periódico puder pertencer a mais de uma área, escolha a PRINCIPAL e anote as secundárias na coluna "Áreas Secundárias"; caso não haja secundárias, deixe com "-" - Não invente informações. Se não reconhecer o periódico, marque confiança BAIXA - Não interrompa a tabela mesmo que a lista seja longa. A resposta deve ser uma única tabela contínua do primeiro ao último periódico LISTA DE PERIÓDICOS: [cole aqui sua lista, um por linha]
💡 Dica: Após colar a lista de periódicos no lugar indicado, envie o prompt. O DeepSeek retornará uma tabela markdown — copie-a inteira (incluindo o cabeçalho) e cole no campo de entrada da aba 🏷️ Classificador de Periódicos.

Como usar

  1. 1Cole a tabela markdown gerada pela LLM no campo de entrada e clique em Processar.
  2. 2Revise e corrija as linhas na tabela — nome, área, confiança e áreas secundárias são todos editáveis.
  3. 3Clique em Exportar JSON para baixar o arquivo padronizado.
